# DEV-8 handoff: Mohar Console

Status (updated as work proceeds): **MVP + Strong + part of Polish built; tests in progress.**

## What exists
`dashboard/` is a Vite + React + TypeScript + Tailwind static site (`npm run build` → `dashboard/dist`, `npm run dev` → http://127.0.0.1:8088).
No backend, no analytics, no secrets. Pins: react 18.3.1, vite 5.4.21, viem 2.57.16, recharts 2.15.0, tailwind 3.4.17.

Pages: Demo Console (scenario controls, Web Serial connect, live 8-stage pipeline with per-stage detail, device log, REPLAY),
Overview, Meter (incl. signal integrity and sensor explorer with "not installed" entries), Verified report, AI insights,
Credit & ledger (wallet top-up / clear hold), Usage, Identity & access (ENS records, root consistency, live dry-run of who may edit a record),
Activity & audit (reports expand to fields, sensors word, frames), Settings (network, name, testing-only manual addresses).

Data sources: ENS on Sepolia via the Universal Resolver (`src/lib/ens.ts`), Mohar devnet RPC (`src/lib/chain.ts`, viem), Web Serial
(`src/lib/serial.ts`) for the Pico (write one char) and ESP (`EV`/`METER` lines per `docs/event-protocol.md`).
Pipeline stage state is derived only from received events (`src/lib/events.ts`); there are no timers advancing stages.

Replay: `dashboard/replay/*.log` (generated by `replay/make-replays.mjs`, copied to `public/replay/`). These follow the protocol but are
**synthesised, not recorded from a run**; the UI badges them REPLAY. Auto-start: `?replay=surge-inspect.log&speed=20`.
